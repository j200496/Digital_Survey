# Digital Survey

## 📌 Overview
This app is a digital survey app to perform surveys with the app you can create the questions and options to choose and have the data in realtime organized in a dashboard ready to download
## 🚀 Tech Stack
- **Frontend:** Angular 17

## ⚙️ How to Run Locally
1. Clone the repo: `git clone [url]`
3. Setup frontend: `npm install`, `ng serve`
